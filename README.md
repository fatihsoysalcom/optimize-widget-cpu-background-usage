# Optimize Widget CPU Background Usage

This example demonstrates how to reduce CPU consumption for a web-based "widget" when its browser tab is not active. It simulates a task that updates frequently when the tab is visible and significantly slows down or pauses when the tab is in the background, thereby conserving system resources. This technique helps prevent unnecessary CPU usage, especially when many tabs are open.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in your web browser.
3. Observe the counter speed and spinner animation, then switch to another browser tab or minimize the browser and switch back to see the throttling effect.
